# 知间 1.0.0 Preview 2

本次更新让查找和连续阅读更顺手。

- 新增专注阅读：点书本按钮或按 ⌘⇧L 收起两侧导航，正文居中；⌘F 返回词库并开始搜索。
- 阅读集支持独立搜索，以及最近阅读、最近收录和名称排序。
- 每篇文章分别记住词条、详情展开状态和滚动位置，重启后恢复；直接定位所在的 60 条分页。
- 新增上一条、下一条按钮及 ⌘↑ / ⌘↓，跨页自动加载；切换词条和阅读模式保留未保存草稿。
- 修正空详情仍能展开、分割线贴近笔记背景、占位文字与光标不齐等问题；加载更多居中，删除重复总数和占位引语卡片。
- 支持确认后永久清空废纸篓，同时清理关系与阅读集引用；CLI 需要 --yes，MCP 需要 confirm: true。

## 下载与更新

macOS 14+；DMG 和 ZIP 都包含 Apple Silicon 与 Intel。Intel 已完成交叉编译及架构检查，尚未做 Intel 实机验收。预览包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证；首次打开方法见 DMG 内说明及 docs/INSTALL.zh-CN.txt。

退出旧版后替换应用，保留 Application Support 中的用户词库。安装包仅包含内置示例，不包含开发者的私人词库。阅读偏好按词库 ID 隔离，不依赖固定安装位置、用户名或开发目录。

## 验证

12 项核心行为检查、真实 CLI/MCP 子进程检查通过。通用应用迁移到含中文和空格的独立目录后，在禁止读取原仓库和构建目录的条件下，通过示例初始化及 CLI/MCP 操作验证。原生界面另验证了专注模式、词条切换、搜索焦点、草稿保留及重启续读。
