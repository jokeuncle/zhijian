# 知间 1.0.0 Preview 3

这次更新改善大词库迁移时的速度和内存占用。

- JSON 备份逐条导出和恢复，兼容旧版备份；导出使用原子替换，导入失败整批回滚。
- 桌面端直接选择 JSON 备份文件，不再受粘贴笔记的 64 MB 限制；大文件只显示前 8 个词名作为预览。
- 复用 SQLite 语句，减少批量写入时的重复编译；及时释放每条记录的临时对象。
- 按钮、菜单、导航行和展开标题使用手形指针；正文及输入区域保留文字选择，禁用控件保留默认指针。

本机 Apple M5 实测，一万条相同长内容词条（新版备份约 155 MB）：导出 1.63 → 0.49 秒，恢复 10.31 → 4.96 秒；导出峰值内存 959 → 17 MB，恢复峰值内存 505 → 105 MB。这是单机合成数据测量，不代表所有设备的速度。完整记录见 docs/migration-performance.json。

## 下载与更新

macOS 14+；DMG 和 ZIP 均包含 Apple Silicon 与 Intel。Intel 已交叉编译并完成架构检查，尚未做 Intel 实机验收。预览包采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名和公证；首次打开方式见包内说明和 docs/INSTALL.zh-CN.txt。

退出旧版后替换应用，保留 Application Support 中的词库。迁移另一台 Mac 时，导出 JSON 备份，再在新电脑选择该文件恢复；已有 ID 会保留，名称冲突时整批取消。备份保留词条内容、来源、笔记及原有状态、关联和阅读集，不包含历史版本或应用偏好。安装包仅包含内置示例。

## 验证

13 项核心行为检查、真实 CLI/MCP 子进程检查、一万词条两种内容规模的逐字段比对，以及重复导入、损坏文件和冲突回滚检查通过。独立临时应用另验证了 72 MB 备份的原生选择、预览和导入，100 条长内容词条的所有字段一致；未触碰用户词库。
