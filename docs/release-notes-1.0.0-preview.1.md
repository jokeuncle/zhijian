# 知间 1.0.0 Preview 1

原生 macOS 个人概念词典：保留大白话解释、文章语境和自己的理解，通过概念关联与回想复习温故知新。

- 三栏阅读界面，文章阅读路径与紧凑关联标签。
- 词条增删改查、个人笔记、收藏、复习、废纸篓与可恢复历史。
- Markdown / JSON 导入导出，内置 15 个学习单元与 5 个对比补充词条。
- 与桌面共用词库的独立 CLI 和 12 个 MCP 工具。
- SQLite、60 条分页、后台搜索、160 ms 防抖与有版本检查的事务写入。

## 下载与运行

macOS 14+，通用 DMG / ZIP 均包含 Apple Silicon 与 Intel；Intel 实机尚未验收。安装后无需 Xcode、Swift、Node.js 或 Python。词库保存在每位用户自己的 Application Support 目录。

本预览版采用 ad-hoc 签名，尚未经过 Apple Developer ID 签名与公证。确认来源及 SHA-256 后，首次被拦截时在“系统设置 → 隐私与安全性”为知间选择“仍要打开”。完整说明附在 DMG 中，亦见仓库 docs/INSTALL.zh-CN.txt。

## 已验证的范围

Apple M5 / macOS 26.4.1：9 组核心行为检查、真实 CLI/MCP 子进程验证、原生界面新建与笔记保存、外部改动刷新、普通/紧凑窗口。通用包在中文与空格的新目录、禁止读取原始项目及构建目录的环境中通过初始化和 CLI/MCP 验收。

独立 10,000 条合成词库：导入约 0.68 秒，首页 60 条 P95 约 6.9 ms，英文搜索约 0.42 ms，中文搜索约 33–37 ms。数据与方法见 docs/performance.md；不包含 160 ms 输入防抖，也不是所有硬件的保证。

尚未实现云同步、全局热键浮窗或应用内自动生成解释。更新时退出旧版，替换应用并保留用户数据目录。
