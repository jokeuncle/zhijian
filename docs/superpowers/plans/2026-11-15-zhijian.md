# 知间 Implementation Plan

> **For agentic workers:** Execute this approved plan inline, task by task. The user's “实现吧” authorizes implementation; no additional choice or approval is required.

**Goal:** Deliver a working native macOS concept dictionary and equally capable local agent interface with measured performance.

**Architecture:** A SwiftPM DictionaryCore library owns SQLite and data operations. SwiftUI and the JSON CLI/stdio MCP server share it. All user data is outside the repository.

**Tech Stack:** Swift 6 toolchain, Swift language mode 5, macOS 14+, SwiftUI, AppKit, Foundation, SQLite3 and XCTest; no third-party dependencies.

**Spec:** docs/superpowers/specs/2026-11-15-zhijian-design.md

## Global Constraints

- macOS 14 or later; no cloud or API key requirement.
- Preserve user notes and article order; label the supplied source truthfully.
- Page size 60, search debounce 160 ms, database work off the main actor.
- Atomic batches, stale-revision rejection, soft deletion, versioned history.
- Measure synthetic 10,000-entry performance in a temporary library.
